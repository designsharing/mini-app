> `openCashier` 的请求参数名为 `prepay_id`，类型为 `string`，用于传入后端返回的预付订单号。

## openCashier

打开收银台

调用路径：`window.chat.openCashier`。

### 接口声明

```typescript
openCashier:  (params: { prepay_id: string }, callback?: (data: object | null) => void) => void
```

### 参数与返回说明

```text
@param params 请求参数
--请求参数
{
  prepay_id: "347djchd-3394-44-98dd-2323dc9cdjc"  //预付订单号 string
}
@param callback 请求后执行函数
@callback response 回调数据结构
--response示例
{
   "appId": "23n34nm43nm34nk34jkx", //小程序ID string
   "orderPayStatus": true,   //订单支付结果 boolean
   "prepayId": "347djchd-3394-44-98dd-2323dc9cdjc" //Flutter 回传字段，预付订单号 string
 }
```

### 调用示例

```javascript
window.chat.openCashier({ prepay_id: "从后端获取预付订单号" }, () => {
  //收银台操作执行完后回调后续操作
})
```

## getRequestAssets

获取用户余额

调用路径：`window.chat.getRequestAssets`。

### 接口声明

```typescript
getRequestAssets: (callback: (response: object | null) => void) => void
```

### 参数与返回说明

```text
@param callback 请求后执行函数
@callback response 回调数据结构
--response示例
{
   data: {
     totalAmt: 0.00,
     totalAmtCurrencyType: "PEA",
     PEA: {
       user_avail: 0.00,
       user_balance: 0.00,
       user_box: 0.00
     }
   }, //返回所传key对应的数据
   code: 0 | 1 //0代表请求正常，并返回数据data；1代表请求报错
}
```

### 调用示例

```javascript
window.chat.getRequestAssets((response) => {
  console.log('用户余额信息', response)
});
```

## sendTransferMessage

发送转账消息，参数字段原样传给 Flutter。调用路径：`window.chat.sendTransferMessage`。

### 接口声明

```typescript
interface SendTransferMessageParams {
  currency: string
  conversationId: number
  txID: string
  amount: string
  remark?: string
  actionUrl: string
}

sendTransferMessage: (
  params: SendTransferMessageParams,
  callback?: (data: object | null) => void
) => void
```

### 参数与返回说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| currency | string | 币种 |
| conversationId | number | 会话 ID |
| txID | string | 订单 ID |
| amount | string | 转账金额 |
| remark | string | 备注，可选 |
| actionUrl | string | 小程序交易详情路由及参数 |

回调在 Flutter 回包后执行，返回结构为 `{ data: {}, code: 0 | 1 }`，其中 `0` 表示正常，`1` 表示报错；回调类型允许 `null`。

### 调用示例

```javascript
window.chat.sendTransferMessage({
  currency: 'USDT',
  conversationId: 12345,
  txID: 'transaction-id',
  amount: '10.00',
  remark: '转账备注',
  actionUrl: '/transfer/detail?txID=transaction-id'
}, (response) => {
  console.log('发送转账消息结果', response)
})
```
