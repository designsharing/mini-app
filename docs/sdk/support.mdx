## getSupportList

获取客服列表，由小程序展示列表。调用路径：`window.chat.getSupportList`。

### 接口声明

```typescript
getSupportList: (labelId: SupportLabelId, callback?: GetSupportListCallback) => void
```

类型定义见仓库 `sdk-global.ts`。`SupportLabelId` 为 `number`，必须是整数，无默认值，不接受数字字符串；非法参数同步抛出 `TypeError`。

### 参数与返回说明

`code === 0` 表示成功，`data.list` 可以为空数组。列表项包含 `nickname`（展示昵称）、`last_online`（最近在线时间，整数，0 也是合法值）和 `uuid`（客服标识），其他字段原样保留。

失败时读取 `data.errorCode`，不补空列表。`uuid` 不要求标准 UUID 格式，且区分大小写；打开会话时应原样传入。

### 调用示例

```javascript
const labelId = 7
window.chat.getSupportList(labelId, (response) => {
  if (response.code === 0) {
    console.log('客服列表', response.data?.list ?? [])
  } else {
    console.error('获取客服列表失败', response.code, response.data?.errorCode)
  }
})
```

## contactCustomerService

根据所选客服 `uuid` 和列表对应的 `label_id` 让客户端打开聊天页。调用路径：`window.chat.contactCustomerService`。

### 接口声明

```typescript
contactCustomerService: (
  params: ContactCustomerServiceParams,
  callback?: ContactCustomerServiceCallback
) => void

interface ContactCustomerServiceParams {
  uuid: string
  label_id: number
}
```

### 参数与返回说明

仅发送 `label_id` 和 `uuid`。`code === 0` 表示已发起打开会话，成功 `data` 为 `{}`；其他 `code` 原样传递。

### 调用示例

```javascript
window.chat.contactCustomerService({ label_id: 7, uuid: 'support_demo_01' }, (response) => {
  if (response.code === 0) {
    console.log('已发起打开客服聊天')
  } else {
    console.error('打开客服聊天失败', response.code, response.data?.errorCode)
  }
})
```
