---
title: "回调与示例约定"
description: "理解不同接口的返回格式和示例边界。"
---

多数回调示例采用以下格式：

```typescript
{
  data: {},
  code: 0 | 1 // 0 表示成功，1 表示报错
}
```

这是结构说明，不是可直接执行的 JavaScript。接口页中的类型联合、占位值同样用于说明允许的值。

不同接口并不完全一致：位置接口列出了 `403`；聊天室跳转和屏幕常亮使用 `success`；文件下载使用 Promise 和进度回调。请以各接口页为准，避免统一假定返回 `code/data`。

现有类型中不少回调允许 `null`，实际业务应先判断返回值，再读取字段。
